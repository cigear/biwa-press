# Biwa Press

Markdown to beautiful SvelteKit docs.

This starter gives you a VitePress-like foundation with SvelteKit routing, mdsvex content, Tailwind CSS 4 styling, Bits UI primitives, and static output.

## Why this exists

- Write content in Markdown.
- Keep the theme in Svelte components.
- Build to static HTML.
- Customize every part of the interface.
