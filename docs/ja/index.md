# Biwa Press

Markdown から美しい SvelteKit ドキュメントへ。

このスターターは、SvelteKit ルーティング、mdsvex コンテンツ、Tailwind CSS 4、Bits UI、静的出力を備えた VitePress 風の土台です。

## 目的

- Markdown でコンテンツを書く。
- Svelte コンポーネントでテーマを管理する。
- 静的 HTML にビルドする。
- インターフェースを自由にカスタマイズする。
