4行日記は、1日5分で自己肯定感を高め、目標達成をサポートする日記メソッドです。
以下の4つの要素（事実・発見・教訓・宣言）を各1行、計4行に順番に書き出すだけで、思考を整理し潜在意識に理想の自分を刷り込めます。

### 【四行日記の基本ルールと手順】
行項目内容のポイント

| <span class="whitespace-nowrap">行</span> | <span class="whitespace-nowrap">項目</span> | 内容のポイント |
| ---- | ---- | :--- |
| <span class="whitespace-nowrap">1行目</span> | <span class="whitespace-nowrap">事実</span> | 今日起きたことや、自分が実際にとった行動をありのままに書く。|
| <span class="whitespace-nowrap">2行目</span> | <span class="whitespace-nowrap">発見</span> | その事実を振り返って、気づいたことや感じたことを書く。|
| <span class="whitespace-nowrap">3行目</span> | <span class="whitespace-nowrap">教訓</span> | 発見（気づき）から得た学びを、自分の原則やルールとして書く。|
| <span class="whitespace-nowrap">4行目</span> | <span class="whitespace-nowrap">宣言</span> | 未来の自分に向けた目標や、「こうありたい」という理想を現在形または完了形で書く。|

### 実践のコツ
1行＝20文字程度、全体で80文字以内を目安にすると、毎日無理なく続けられます。決まった記号（例：◆事実、●発見、★教訓、■宣言）を使って枠組みを意識しやすくするのもおすすめです。もっと手軽に始めたい場合は、専用のアプリ（App Store / Google Play）を活用するのも便利です。
